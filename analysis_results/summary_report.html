Simulation disagreement summary

This report compares per-iteration distance traces from the unified simulator and the CLI simulador_heuristica.simulator runs. Files used are under the analysis_results/ folder in the project.

Available artifacts

  • comparison_summary.json — aggregated metrics per seed.
  • comparison_ratios.csv — unified/CLI distance ratios per seed.
  • disagreement_summary.csv — RMSE/MAE per seed (aligned series).
  • top_disagreement_report.json — top seeds diagnostics (JSON).
  • Per-seed files:
    • Unified series: unified_seed_<n>.json
    • CLI series: cli_seed_<n>.json
    • Detail CSVs: detail_seed_<n>.csv
    • Overlay plots: plots_overlay/overlay_seed_<n>.png

Quick actions

  1. Open overlay images: analysis_results/plots_overlay/
  2. Open per-seed detail CSVs for top seeds: analysis_results/detail_seed_*.csv
  3. To reproduce: run the CLI as described in the repository README (or run python -m simulador_heuristica.simulator.main -e sim_mapa3 -m <seed> -s <seed>).
