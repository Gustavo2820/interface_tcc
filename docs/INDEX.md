# Índice do Sistema

Índice geral e navegação rápida para a documentação do projeto.

## Documentos principais

- `USER_GUIDE.md` — Guia do Usuário (uso da interface, criação de mapas, execução e análise de resultados)
- `ARCHITECTURE.md` — Arquitetura do sistema (visão geral e fluxos de execução)
- `DEVELOPMENT.md` — Guia de desenvolvimento (APIs, exemplos, integrações, como estender o projeto)
- `UNIFIED_CONFIG_FORMAT.md` — Formato unificado de configuração (presets e exemplos)
